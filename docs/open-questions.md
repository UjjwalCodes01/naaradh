## How to close one

1. Get the answer **in writing** from a primary source (TSP letter, vendor invoice, regulator text, lawyer's opinion) and file it — TSP replies in `docs/legal/tsp-responses/`, vendor answers alongside the bake-off sheet.
2. If the answer changes a decision, write an ADR in `docs/decisions/`.
3. Set the row to `closed` with a link to the evidence. Do not delete the row.
